# Project: Aman Bhaiya Portfolio

## Overview
This is a personal portfolio website for Aman Bhaiya, a Strategy and Growth executive. The website highlights his experience, education, and skills.

## Structure
- Single page layout
- Components: Hero, Experience, Education, Skills, Contact
- Styling: Tailwind CSS (Corporate/Modern theme)

## Maintenance
- Update `components/Experience.js` to add new roles.
- Update `components/Skills.js` to modify skill sets.
